# VenturePlus mobile demo

Native Flutter, Android first with iOS-compatible source. Staff operate property
inventory and customer workflows; customers access their own linked properties.
Agent is distinct from Employee. GUIDELINES.md and docs/SOURCE-AUDIT.md govern scope.

The visual world is settled by DESIGN.md: light sage/walnut/amber, calm surfaces,
real logo, native controls, bottom navigation and secondary menu, responsive
phone/tablet layouts. Operate is the mode for all app surfaces. System typography
is the approved offline fallback. No image-generated design comp is needed.

Connected mode uses cookies/CSRF and server identity. Offline Demo uses fictional
local data and never sends changes to the backend. No payments, push or invented KPIs.

Login answers “How do I enter my workspace?” with sign-in, prefill-only buttons
and a separate Offline Demo entry. Inventory answers “Which location, venture and
plot am I viewing?” with hierarchy, status labels and plot geometry. Actions follow
verified permissions. The owner's detailed brief settles purpose and direction.

UI/UX Pro Max's generic glassmorphism/fonts conflict with the brief and are rejected;
its Flutter LayoutBuilder/Semantics guidance applies. Video taste is inapplicable.
App-screen taste and Impeccable craft guidance inform hierarchy, honest states,
restrained elevation and bounded visual review.
